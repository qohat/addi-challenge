⏺ docs/adr/0008-domain-shapes-and-the-single-collapse-point.md — types and cases
  only, no bodies.

  What it fixes:

  - Lead vs prospect — Prospect(Lead, int score) differs by evidence, not a
  status field, and is constructed at one site only.
  - Four outcome hierarchies under a marker StepOutcome (no type parameter, no
  shared success/failure vocabulary — not the Result ADR 0005 rejects). The
  marker exists for one reason: it makes the collapse a single switch instead of
  four.
  - RejectionCause — five cases now, with 05's ScoreBelowThreshold and 06's
  ReviewRejected marked in place.
  - Decision — three cases, three exit codes; exit 3 is deliberately not one of
  them.
  - Checkpoint — Checkpoint(Lead, Step pending, String reason). This is the one
  place I went past transcription: ADR 0004 says the case persists the outcomes
  already resolved, and those are determined by pending (a step that resolved
  before the checkpoint resolved cleanly, or the run ended there). Storing them
  too is a second copy free to disagree with pending. So the file stores the
  step, and resume becomes run(lead, from) with no prefix to inject.
  - Four ports, uniform Lead in / own outcome out, synchronous — plus
  LeadRepository, which spec 01 also needs and nothing had decided.
  - The collapse — Optional<Decision> terminal(Lead, StepOutcome), thirteen
  arms, no default. Four arms are Unavailable, one per step, each naming its own
  step as a literal because the matched case already says where it came from —
  that is how the checkpoint gets pending without a caller passing one. Nothing
  else in the system constructs PendingManualReview.

  Queue: 01 high → medium, with the reason in the "why this order" paragraph. I
  lowered it honestly — after the ADR, what's left to 01 is package layout,
  where terminal lives, and what the stubs return, none of which later specs sit
  on. The one thing that would have kept it high was the pipeline entry
  signature (06 sits on it), so I decided that too rather than lower the label
  over it.

  Not committed — say the word and it goes on main as one docs commit.
